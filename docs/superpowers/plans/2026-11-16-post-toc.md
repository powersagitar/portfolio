# Post Contents Column Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a sticky "On this page" column to post pages and the board's body details (section numbers, `#` links, code labels, new note style), with smooth in-page scrolling.

**Architecture:** A pure `outlineFromMdx` reads `##` headings and code-block count from post source at build time; the server page passes them to a client `Toc` that only tracks scroll. Body details are CSS plus two MDX component changes; the RSS feed overrides them away.

**Tech Stack:** Next.js 16 App Router, `@next/mdx`, `mdast-util-from-markdown`, `mdast-util-to-string`, `github-slugger`, `gray-matter`, Tailwind, `bun test`.

**Spec:** `docs/superpowers/specs/2026-11-16-post-toc-design.md`

## Global Constraints

- Bun only (`bun add`, `bun test`, `bun run …`). Only lockfile is `bun.lock`.
- Post prose in `content/` is never edited.
- `type`, not `interface`. Prettier: single quotes, semicolons, trailing commas; import order React, Next, third-party, `@/`, `@content/`, relative.
- Palette only: `#000`, `#f5f5f7`, `#d1d1d6`, `#86868b`, `#6e6e73`, `#2c2c2e`, `#1d1d1f`, `#48484a`, `#0d0d0d`.
- Body stays on the title's left edge, `max-width: 760px`; the rule above the body stays 760px wide on desktop.
- Grid: `minmax(0, 760px) minmax(0, 1fr) 248px`, `column-gap: 48px`; one column at `max-width: 1100px`; phone `max-width: 700px`.
- `prefers-reduced-motion: reduce` → no smooth scroll, no rail transition.
- Filesystem access only in `server-only` modules under `src/lib/`.
- Hash updates use `history.replaceState` (no history entry).

## Review Focus

- A post's frontmatter `title:` line followed by `---` must not be read as a setext `##` heading (strip frontmatter first). → Task 1 test.
- Heading ids must match what `rehype-slug` renders, including duplicates across levels (one slugger over all headings in order). → Task 1 test + Task 4 build check.
- Inline code in a heading (`` `if-else` Statements``) gives label `if-else Statements`, id `if-else-statements`. → Task 1 test.
- Before the first heading reaches the line, and past the end of the article, active/progress stay in range (0, clamped 0–1). → Task 2 test.
- The feed must not gain `#` links or code-label strips. → Task 3 test.
