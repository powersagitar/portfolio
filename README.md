# Portfolio

Personal portfolio and blog: a Next.js 16 App Router site with MDX posts and a
dot cloud that morphs as you move through the index. Bun only.

## Commands

```sh
bun install
bun run dev
bun run build
bun run start
bun run test
bun run lint
bun run prettier:check
```
